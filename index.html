Hermes

Hermes es un asistente personal de uso privado. Lo opera únicamente su dueño, Edwar Santana, en un servidor propio en Bogotá, Colombia. No es un producto comercial, no tiene usuarios distintos de su dueño y no se ofrece como servicio a terceros.

Esta página es pública y no tiene inicio de sesión, formularios ni muros de acceso: existe para explicar qué es la aplicación, para qué pide acceso a una cuenta de Google y cómo trata los datos.

Para qué existe la aplicación

El objetivo de Hermes es ahorrarle a su dueño el trabajo manual de mantener sus propios registros. Concretamente:

  • Finanzas personales: anotar cifras del dólar y gastos del hogar en hojas de cálculo privadas del dueño.
  • Documentación propia: mantener actualizados documentos de referencia en el Drive del dueño (sus notas y guías de trabajo).
  • Resúmenes: enviarle al propio dueño un resumen diario por su canal de mensajería (Telegram).

Por qué pide acceso a Google

Las hojas, los documentos y los archivos viven en la cuenta de Google del dueño. Para leerlos y actualizarlos, la aplicación usa las API de Google con permiso explícito del dueño. Solo se solicitan los permisos que las tareas necesitan:

  • Google Sheets — leer y escribir en las hojas del dueño.
  • Google Drive — leer y crear archivos en sus carpetas.
  • Google Docs — leer y actualizar sus documentos.

Al autorizar, Google muestra una pantalla de consentimiento. Si aparece el aviso de «aplicación no verificada», es porque Google no audita herramientas de uso personal de un solo usuario; no significa que el acceso sea anónimo: la aplicación solo puede entrar con la autorización que el propio dueño da, y puede revocarla en cualquier momento.

Uso responsable de las API de Google

Hermes cumple las Condiciones del Servicio de las API de Google. En particular:

  • No usa las API para generar, difundir ni facilitar contenido sexual no consentido (NCII) ni material de abuso, y no emplea modelos de IA para producir ese tipo de contenido.
  • No revende, sublicencia ni redistribuye datos obtenidos de las API de Google.
  • No usa los datos para publicidad, perfilado comercial ni entrenamiento de modelos de terceros.
  • No intenta eludir los límites de cuota ni las restricciones de acceso de Google.
